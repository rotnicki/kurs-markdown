Kurs przedstawia celowo ograniczony, podstawowy zestaw składni, który jest czytelny i przenośny pomiędzy różnymi narzędziami.

## Podstawy standardu

- [CommonMark Specification](https://spec.commonmark.org/current/) — opis podstawowej składni Markdown, między innymi akapitów, nagłówków, list, cytatów, wyróżnień i linków.
- [GitHub Flavored Markdown Specification](https://github.github.com/gfm/) — odmiana CommonMark używana przez GitHub.
- [Podstawowa składnia pisania i formatowania na GitHubie](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax) — oficjalna dokumentacja GitHuba.

## Publikowanie kursu

- [Tworzenie witryny GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) — oficjalna instrukcja GitHuba.
- [Konfigurowanie źródła publikacji GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) — publikowanie z gałęzi i folderu `/docs`.

## Dostępność GitHuba

- [Korzystanie z repozytoriów GitHub za pomocą czytnika ekranu](https://accessibility.github.com/documentation/guide/repos/) — oficjalny przewodnik GitHuba przygotowany między innymi dla NVDA w Windows.

## Zakres kursu

W kursie celowo pominięto bardziej zaawansowane elementy, takie jak:

- tabele;
- przypisy;
- zagnieżdżone listy;
- kod HTML;
- metadane YAML;
- automatyczne generowanie dokumentów;
- obsługa systemu publikowania treści.

Można je dodać później jako osobny poziom zaawansowany.
