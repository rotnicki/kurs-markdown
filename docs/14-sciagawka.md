## Akapit

Pomiędzy akapitami pozostaw jeden pusty wiersz.

```markdown
Pierwszy akapit.

Drugi akapit.
```

## Nagłówek poziomu pierwszego

```markdown
# Nagłówek poziomu pierwszego
```

## Nagłówek poziomu drugiego

```markdown
## Nagłówek poziomu drugiego
```

## Nagłówek poziomu trzeciego

```markdown
### Nagłówek poziomu trzeciego
```

## Lista punktowana

```markdown
- pierwszy element
- drugi element
- trzeci element
```

## Zagnieżdżona lista punktowana

Elementy listy wewnętrznej rozpocznij od czterech spacji.

```markdown
- Dokumenty:
    - legitymacja
    - zgoda opiekuna
- Wyposażenie:
    - strój sportowy
    - woda
```

## Lista numerowana

```markdown
1. pierwszy krok
2. drugi krok
3. trzeci krok
```

## Zagnieżdżona lista numerowana

Elementy listy wewnętrznej rozpocznij od czterech spacji.

```markdown
1. Przygotuj dokument.
    1. Napisz treść.
    2. Dodaj nagłówki.
2. Sprawdź dokument.
```

## Pogrubienie

```markdown
**ważny tekst**
```

## Kursywa

```markdown
*tytuł lub wyróżniony tekst*
```

## Link

```markdown
[Opis linku](https://example.com)
```

## Cytat

```markdown
> Treść cytatu.
```

## Obraz

```markdown
![Krótki tekst alternatywny](https://example.com/obraz.jpg)
```

## Kontrola przed przekazaniem dokumentu

- Jeden nagłówek poziomu pierwszego.
- Logiczna kolejność nagłówków.
- Puste wiersze pomiędzy akapitami.
- Każdy element listy w osobnym wierszu.
- Cztery spacje przed elementami listy wewnętrznej.
- Opisowe teksty linków.
- Zamknięte pary gwiazdek i nawiasów.
- Brak przypadkowych znaków.
