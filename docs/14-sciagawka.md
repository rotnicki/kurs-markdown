## Akapit

Pomiędzy akapitami pozostaw jeden pusty wiersz.

```markdown
Pierwszy akapit.

Drugi akapit.
```

## Tytuł

```markdown
# Tytuł dokumentu
```

## Główna część

```markdown
## Nazwa części
```

## Mniejsza część

```markdown
### Nazwa mniejszej części
```

## Lista punktowana

```markdown
- pierwszy element
- drugi element
- trzeci element
```

## Lista numerowana

```markdown
1. pierwszy krok
2. drugi krok
3. trzeci krok
```

## Pogrubienie

```markdown
**ważny tekst**
```

## Kursywa

```markdown
*tytuł lub wyróżniony tekst*
```

## Link

```markdown
[Opis linku](https://example.com)
```

## Cytat

```markdown
> Treść cytatu.
```

## Obraz

```markdown
![Krótki tekst alternatywny](https://example.com/obraz.jpg)
```

## Kontrola przed przekazaniem dokumentu

- Jeden tytuł poziomu pierwszego.
- Logiczna kolejność nagłówków.
- Puste wiersze pomiędzy akapitami.
- Każdy element listy w osobnym wierszu.
- Opisowe teksty linków.
- Zamknięte pary gwiazdek i nawiasów.
- Brak przypadkowych znaków.
