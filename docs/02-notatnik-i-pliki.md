## Czego nauczysz się w tej lekcji

Po tej lekcji będziesz umieć:

- utworzyć dokument w Notatniku;
- zapisać go jako plik Markdown;
- rozpoznać rozszerzenie `.md`;
- uniknąć przypadkowego zapisania pliku jako `.md.txt`.

## Czego potrzebujesz

Do podstawowej nauki wystarczy zwykły Notatnik systemu Windows. Markdown nie wymaga specjalnego edytora.

## Co oznacza `.md`

Rozszerzenie `.md` informuje, że plik zawiera tekst zapisany w Markdown.

Przykładowe nazwy:

```text
wyniki-zawodow.md
komunikat-zarzadu.md
zaproszenie-na-zebranie.md
```

## Jak zapisać pierwszy plik

1. Otwórz Notatnik.
2. Wpisz krótkie zdanie.
3. Otwórz polecenie **Zapisz jako**.
4. W polu nazwy wpisz na przykład:

```text
pierwszy-dokument.md
```

5. Jeżeli pojawi się wybór typu pliku, wybierz **Wszystkie pliki**.
6. Pozostaw kodowanie UTF-8.
7. Zapisz dokument.

## Jak sprawdzić nazwę

Prawidłowa nazwa kończy się dokładnie tak:

```text
.md
```

Nieprawidłowy przykład:

```text
pierwszy-dokument.md.txt
```

To nadal byłby zwykły plik tekstowy, ale system rozpoznawałby go przede wszystkim jako plik `.txt`.

## Rozsądne nazwy plików

Najprościej używać:

- małych liter;
- cyfr;
- łączników zamiast spacji;
- nazw opisujących zawartość.

Przykład:

```text
2026-07-20-wyniki-showdown.md
```

Nie jest to obowiązkowa zasada Markdown. Pomaga jednak utrzymać porządek.

## Czytnik ekranu i znaki interpunkcyjne

Markdown korzysta ze znaków takich jak:

```text
# * - > [ ] ( ) `
```

Czytnik ekranu może nie wypowiadać wszystkich znaków przy niskim poziomie oznajmiania interpunkcji. Podczas sprawdzania składni warto:

- zwiększyć poziom oznajmiania interpunkcji;
- czytać problematyczny fragment znak po znaku;
- używać klawiszy strzałek do sprawdzenia początku wiersza.

## Ćwiczenie

Utwórz w Notatniku plik o nazwie:

```text
cwiczenie-01.md
```

Wpisz w nim:

```text
To jest mój pierwszy dokument Markdown.
```

Zapisz plik, zamknij Notatnik i otwórz dokument ponownie.

## Rozwiązanie

Plik powinien nazywać się:

```text
cwiczenie-01.md
```

Po ponownym otwarciu powinien zawierać dokładnie jedno zdanie.
