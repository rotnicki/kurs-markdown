## Czego nauczysz się w tej lekcji

Po tej lekcji będziesz umieć:

- pogrubić ważny fragment;
- zapisać fragment kursywą;
- nie mylić wyróżnienia z nagłówkiem.

## Pogrubienie

Pogrubienie tworzymy za pomocą dwóch gwiazdek przed tekstem i dwóch po tekście.

```markdown
**Termin zgłoszeń upływa 15 sierpnia.**
```

Ważne: pomiędzy gwiazdkami a tekstem nie wstawiaj spacji.

Prawidłowo:

```markdown
**ważna informacja**
```

Nieprawidłowo:

```markdown
** ważna informacja **
```

## Kursywa

Kursywę tworzymy za pomocą jednej gwiazdki przed tekstem i jednej po tekście.

```markdown
*Memoriał imienia Jana Kowalskiego*
```

## Pogrubienie i kursywa jednocześnie

Można użyć trzech gwiazdek:

```markdown
***Bardzo ważna informacja***
```

W podstawowych dokumentach rzadko jest to potrzebne.

## Kiedy używać wyróżnienia

Pogrubienie może zaakcentować:

- termin;
- krótkie ostrzeżenie;
- ważną zmianę;
- najistotniejszy fragment zdania.

Kursywa może oznaczać:

- tytuł;
- nazwę publikacji;
- delikatne zaakcentowanie słowa.

## Czego unikać

Nie pogrubiaj całych długich akapitów. Nie używaj pogrubienia zamiast nagłówka.

Nie przekazuj ważnej informacji wyłącznie przez wygląd. Czytnik ekranu może nie oznajmiać pogrubienia lub kursywy przy domyślnych ustawieniach.

Zamiast:

```markdown
Zgłoszenia przyjmujemy **do piątku**.
```

lepiej napisać także jednoznacznie:

```markdown
Termin zgłoszeń: **piątek, 15 sierpnia, godzina 18:00**.
```

## Ćwiczenie

Wyróżnij termin w zdaniu:

```text
Zgłoszenia przyjmujemy do 20 września.
```

Zapisz nazwę zawodów kursywą:

```text
Puchar Polski w showdownie
```

## Rozwiązanie

```markdown
Zgłoszenia przyjmujemy **do 20 września**.

*Puchar Polski w showdownie*
```
